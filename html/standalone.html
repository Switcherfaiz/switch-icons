Use independently

v1 is CSS-only. There is no peerDependencies.switch-framework. Any HTML page can load the font.

Install

npm i switch-icons

Then open these files in a browser:

node_modules/switch-icons/html/index.html
node_modules/switch-icons/html/icons.html

Link the CSS from your page

<link rel="stylesheet" href="./node_modules/switch-icons/style.css">

<span class="switch_icon_heart" aria-hidden="true"></span> Save
