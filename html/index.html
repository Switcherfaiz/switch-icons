switch-icons

First-party icon font for Switch Framework. CSS classes, no bundler, no allowlist. After npm i switch-icons, open these HTML files from node_modules/switch-icons/html/.

Use with Switch Framework Use in any HTML page Browse the catalog

Install

npm i switch-icons

Class API

Keep using switch_icon_… class names:

<span class="switch_icon_magnifying_glass" aria-hidden="true"></span>
