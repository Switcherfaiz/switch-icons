Use with Switch Framework

create-switch-framework-app installs this package next to switch-framework and switch-framework-backend. Do not add switch-icons to switchFramework.imports — that list is for third-party packs. Icons are part of the SDK and are always on the import map.

1. One global stylesheet (simplest)

Put this in index.html so @font-face is on the document:

<link rel="stylesheet" href="/switch-icons/style.css">

2. Inside a component styleSheet()

CSS @import does not use the JavaScript import map. Use the mapped HTTP URL:

styleSheet() {
  return `
    <style>
      @import url('/switch-icons/style.css');
      .btn { display: inline-flex; align-items: center; gap: 8px; }
    </style>
  `;
}

render() {
  return `<button class="btn"><span class="switch_icon_magnifying_glass" aria-hidden="true"></span>Search</button>`;
}

Do not

Do not write import 'switch-icons/style.css' from JavaScript. That is a bundler feature. This stack has no bundler. Do not copy assets/icons into every app — install this package instead.
